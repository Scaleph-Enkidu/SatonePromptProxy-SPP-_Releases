# 聪音 Mod：让对话延续，让关系慢慢成长

> 今天聊过的事，可以成为下一次见面的共同记忆。

**这是为《放松时光：与你共享Lo‑Fi故事》（Chill with You : Lo-Fi Story）Steam Windows 版制作的非官方 AI 互动模组。** 它让你能够在熟悉的 Lo-Fi 房间里，通过打字或麦克风与聪音自由交谈，听她用日语回答，并阅读中文字幕。对话可以留下记忆，相处可以影响关系；你也可以亲自调整她的人物设定。

你可以聊今天的生活，接着讨论上次没有聊完的话题，或者问她是否还记得以前的一件小事。本项目希望让这些交流逐渐形成属于当前档案的共同经历，同时保留聪音自己的性格、意见与相处边界。

**本 Mod 由 AIChat Remake 与 SatonePromptProxy（SPP）共同工作。** AIChat 负责游戏内聊天、字幕、语音与交互；SPP 负责人格、记忆、好感度和服务连接。AI 回答需要付费的 OpenAI API，完整语音与麦克风体验需要另外配置本地服务；费用和安装难度见下文。

## 这个模组能带来什么

### 可以持续积累、按需找回的长期记忆

**让相处有过去，也能接着往下聊。** 正常完成的对话会保留本地原文；聊天变长后，SPP 会整理长期记忆、保留一部分近期对话，并在需要时从旧记录中寻找相关内容。

你提起“还记得我们上次聊过的事吗”时，默认会触发旧对话检索。检索服务配置完成后，可以使用本地文字搜索，并在语义模型就绪时按意思寻找相近内容，将命中的片段交给聪音参考。

这里的 **“近乎无限记忆”指本地记录可以在存储空间允许的范围内持续积累，原文不会因为自动整理模型上下文而被一并删除**。模型每次能读取的内容仍然有限，摘要可能遗漏细节，检索也可能没有命中；因此不能保证任何年代、任何细节都能准确想起。旧对话检索需要另外配置 Python 与本地检索环境，存下记录不等于检索服务已经就绪。

### 会随着相处变化的好感度与关系

**你们如何相处，会影响之后怎样交谈。** 系统分别记录喜欢程度、信任、相处舒适度与开放程度，并据此形成综合好感和关系阶段。这些状态参与生成回答，影响她愿意分享多少、如何回应亲近的请求，以及对当前关系的理解。

默认规则鼓励真实交流、尊重与可靠的相处，抑制重复刷同一句话来增加数值。关系加深后，她仍保留自己的意见与拒绝权。相关变化由模型判断与程序规则共同处理，目前仍可能判断不准。

### 可以完整阅读、调整的人格设定

**从她怎样思考，到她怎样表达，都有可编辑的设定。** 聪音的身份、性格、说话习惯、兴趣、知识边界、主动性和关系倾向保存在独立人格文件中。你可以阅读并修改完整文本，让相处方式更贴近自己的创作设想。

当前默认文件为 `SatonePersona_v4.5.txt`。修改后可通过 SPP Dashboard 的 **Reload Persona** 重新加载，无需为修改人格而清空聊天和长期记忆。人格由三个档案共同使用，改动会影响它们；“完整可编辑”不代表能保证模型每句都严格遵守设定。

### 还有这些日常体验

| 功能 | 使用时意味着什么 |
|---|---|
| 三套独立记忆档案 | 各自保存对话、长期记忆与 AI 关系，可以分开体验不同的相处过程。人格文件全局共用；记忆3默认是高好感测试档 |
| 打字、按住说话与持续通话 | 可以使用键盘，也可以按住 F8 说话，或开启持续通话；麦克风输入需要 Fun-ASR 正常运行 |

## 记忆和存档文件保存在哪里

**SPP 的记忆与关系档案默认保存在你放置 `SatonePromptProxy.exe` 的文件夹内。** 例如按教程安装到 `D:\LofiMOD\SatonePromptProxy`，记忆1的目录就是：

```text
D:\LofiMOD\SatonePromptProxy\memory_profiles\记忆1\
```

记忆2、记忆3使用同层的 `记忆2`、`记忆3` 文件夹。下面列出默认文件；自定义配置或旧版安装可能使用其他位置。

| 文件 | 保存的内容 |
|---|---|
| 档案内 `SatoneArchive.jsonl` | 已成功归档的完整对话原文，供历史检索使用 |
| 档案内 `SatoneChat.txt` | 便于直接阅读的聊天记录 |
| 档案内 `SatoneMemory.json` | 整理后的长期记忆 |
| 档案内 `SatoneRelationship.json` | 当前档案的 AI 好感与关系状态 |
| 档案内 `SatoneRecall.db` | 本地检索数据库 |
| 档案内 `conversation_state.json` | 与远端会话关联的本地状态 |
| SPP 根目录 `SatonePersona_v4.5.txt` | 默认人格文本，由三个档案共用 |
| SPP 根目录 `OriginalGameProgress.json` | 原版共同经历账本 |

游戏内窗口显示的历史另存在 `游戏目录\BepInEx\config\AIChatSatoneUX.history`，API Key 等设置存在同目录的 `com.username.chillaimod.cfg`。窗口显示多少条历史，不等于长期归档只保留多少条。

备份时请先退出游戏和服务，至少保留整个 `memory_profiles`、SPP 配置、实际使用的人格文件和原版经历账本，并另存 AIChat 的配置与历史。**这些文件可能含私人对话和密钥，不能作为安装包发给别人。** 本地保存也不代表聊天只存在本机：默认方案仍会向 OpenAI 发送聊天及所需上下文，并使用远端会话。完整位置、迁移和隐私说明见[本地数据与隐私](docs/DATA_AND_PRIVACY.zh-CN.md)。

**安装教程草稿 v4 · 功能核查日期 2026-09-27（日本时间）· 当前配对：AIChat 1.16.14 + SPP 5.8.23。** 功能介绍以当前版本为准，[实现依据与验证边界](docs/MAINTAINER_STATUS.zh-CN.md#首页功能介绍的实现依据)另有记录。

## 安装前先读：你需要自行支付 OpenAI API 费用

**这是开始安装前最重要的条件。当前教程使用 OpenAI API 生成聪音的回答，玩家必须准备自己的 API Key，并开通 API 计费或按 OpenAI 页面要求购买可用额度。没有可用的 API 服务，安装两个插件也不能让聪音进行 AI 对话。**

这里说的是 OpenAI API，不是登录 ChatGPT 网页。购买游戏、下载 Mod 或订阅 ChatGPT Plus/Pro，都不等于已经为这个 Mod 购买 API 用量。本教程目前没有经过验证的纯离线主聊天模型安装方案。

**推荐使用 GPT-6 Luna，在模型名称一栏准确填写 `gpt-6-luna`。** 先查看 [OpenAI 官方模型说明](https://developers.openai.com/api/docs/models/gpt-6-luna)、[API 价格](https://developers.openai.com/api/docs/pricing)与[计费页面](https://platform.openai.com/settings/organization/billing/overview)，确认自己的账户能够使用，再到 [API Key 页面](https://platform.openai.com/api-keys)创建密钥。具体付款方式、地区要求与额度以 OpenAI 页面为准。

### 大概会花多少钱

API 按处理的 token 收费，**不会按照“说一句固定扣多少钱”收费**。本页把“玩家发一条消息，聪音回复一次”记为 1 轮。人格、记忆、旧对话、好感更新、记忆整理与推理过程都会影响用量。

2026-09-26 核对的 GPT-6 Luna Standard 单价为：每百万 token，普通输入 **$0.10**、缓存命中输入 **$0.01**、写入缓存输入 **$0.125**、输出 **$0.50**。原文数值、计算公式和完整前提见[费用说明](docs/API_COST.zh-CN.md)。

下面只是**预算演算，不是实测均值或费用上限**。将主聊天和所有辅助请求均摊到每轮；人民币按 **$1 = ¥7 的示例汇率**换算，未含税费及手续费。未命中的输入全部按较高的缓存写入价计算，输出包含推理 token。

| 演算前提 | 每天 100 轮 | 连续 30 天，共 3,000 轮 | 假设有 $5 余额，每天 100 轮约能用 |
|---|---:|---:|---:|
| 每轮合计 30,000 输入、1,000 输出；90% 输入命中缓存 | $0.1145，约 ¥0.80 | $3.435，约 ¥24.05 | 43.7 天 |
| 同样的输入和输出，但没有缓存命中 | $0.425，约 ¥2.98 | $12.75，约 ¥89.25 | 11.8 天 |
| 每轮合计 50,000 输入、4,000 输出；没有缓存命中 | $0.825，约 ¥5.78 | $24.75，约 ¥173.25 | 6.1 天 |

例如，在第二种假设下，1,000 轮相当于每天 100 轮聊 10 天，约花 **$4.25 / ¥29.75**。$5 不是最低充值额或套餐，天数也不代表额度有效期。实际消耗可能超过这些例子；请以 [OpenAI 用量页](https://platform.openai.com/usage)和账单为准。

**当前 SPP 5.8.23 的内置价格表尚未包含 `gpt-6-luna`，面板显示 0 或未知不等于免费。** [费用说明](docs/API_COST.zh-CN.md)提供了本地估算表的填写方法。

## 安装前需要知道

- 两个 Mod 安装包不包含 GPT-SoVITS、Fun-ASR 模型、声线权重或参考录音。完整语音功能需要额外下载与配置。
- 本教程限定 Windows 64 位。完整本地语音流程优先在兼容 NVIDIA 显卡的电脑上验证；本项目尚未给出经过实测的最低显存或 CPU 实时性能保证。
- 请通过 Steam 启动游戏，以便读取有效身份。身份不可用时，受影响的是原版经历同步及其好感叠加，不等于所有 AI 聊天和 AI 好感都会失效。
- 更新 DLL 后仍显示旧接口和聊天记录，通常是读取了旧配置。不要向别人发送自己使用过的整个游戏目录或 SPP 目录。
- SPP 5.8.23 的新记忆整理阈值尚无游戏内长对话验收记录。正式 Release 不代表所有设备与分支都已经实测。

本仓库提供教程和两份正式插件包，不包含游戏模型、游戏音频、玩家密钥或玩家存档。外部程序、模型与录音的使用条件以原发布页为准。
