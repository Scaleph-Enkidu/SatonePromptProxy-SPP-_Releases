# API の費用

[ホーム](README.md) · [接続](systems/CONNECTIONS.md) · [プライバシー](DATA_AND_PRIVACY.md)

パッケージに API 利用枠は付属しません。自分のサービスアカウント、API 権限、残高が必要です。ChatGPT の定額契約と API のクレジットは別です。標準モデル名は変更可能な例なので、利用可否を提供元で確認してください。

## 課金対象

要求には入力だけでなく人格、最近の会話、記憶、規則が含まれます。関係・記憶更新、形式修復、再試行で追加要求が発生する場合があります。推論 token やキャッシュの区分も料金に影響します。画面上の 1 往復が API 1 回とは限らず、失敗・キャンセルでも使用量が生じます。

実際の料金表と請求を確認してください：[OpenAI 料金](https://openai.com/api/pricing/)、[モデル](https://developers.openai.com/api/docs/models)、[使用量](https://platform.openai.com/usage)、[請求](https://platform.openai.com/settings/organization/billing/overview)、[DeepSeek 料金](https://api-docs.deepseek.com/quick_start/pricing)。中継サービスでは別料金の場合があります。この説明は 1 回あたりの固定料金を保証しません。

```text
費用 = 各課金区分の使用量 × その時点の単価、の合計
完了 1 往復あたりの実測費用 = 測定期間の総費用 / 完了往復数
推定日数 = 残高 /（1 往復の実測費用 × 1 日の想定往復数）
```

キャッシュ入力を二重計上しないでください。バックグラウンド要求も含め、税・手数料・課金規則は実際の請求に従います。概算は支出上限ではありません。少数の会話で試し、提供元の使用量を確認してください。通知しきい値が自動停止を意味するとは限りません。

SPP のローカル料金表は古い可能性があります。0 や不明の表示は無料を意味しません。返されたモデル識別子で照合するため、過去の請求を正確に再現する保証もありません。2026-10-01 のローカル確認は、全サービスの課金組み合わせを検証したものではありません。

ローカル ONNX・GPT-SoVITS・Fun-ASR を動かすだけで OpenAI 音声 API を使うわけではありませんが、機器の資源と電力は消費します。リモート音声サービスに変更した場合は、その料金・条件に従います。
