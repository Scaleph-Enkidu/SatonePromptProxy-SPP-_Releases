# データ、バックアップ、プライバシー

[ホーム](README.md) · [更新](UPGRADE.md) · [API 費用](API_COST.md)

ローカル保存とサービス側の処理は別です。クラウド会話では、選択された文脈を指定先へ送ります。自分の実行フォルダーを配布用のクリーンなパッケージとして公開しないでください。

## ローカルの保存場所

| 場所 | 内容・注意 |
| --- | --- |
| `BepInEx/config/com.username.chillaimod.cfg` | プラグイン設定、キーの下書きが残る場合がある |
| `BepInEx/config/AIChatSatoneUX.history` | 画面履歴。Base64 は暗号化ではなく、全記憶でもない |
| `BepInEx/LogOutput.log` | 認識文、返答、TTS 情報、パスを含む場合がある |
| SPP の `config.json` | アドレス・パス。標準の認証保存先は別 |
| `connections.v1.json`、`connection_credentials.v1.json` | 接続と認証情報・API Key |
| `SatonePersona_v4.6.txt` | 共有人格。独自内容には私的情報が入り得る |
| `local_v1/commits.jsonl`、`active_selection.v1.json` と関連ロック・復旧ファイル | 正本記録・状態。削除可能なキャッシュではない |
| `memory_profiles/memory1/local_v1` など | 各プロファイルの記録・投影。すべて保持する |
| 旧 `记忆1`、`记忆2`、`记忆3`、`SatoneMemory.json`、`SatoneRelationship.json`、`SatoneArchive.jsonl`、`SatoneChat.txt`、`SatoneRecall.db` | 新旧データが同居する場合がある |
| `semantic_recall_v1` | 私的なテキスト指紋・ベクトル。再構築可能でも公開可能ではない |
| `models/multilingual-e5-small` | 汎用モデル。個人会話の記憶ではない |
| `OriginalGameProgress.json` と復旧コピー | ゲーム識別・進行から作る台帳 |
| `runtime_paths.json`、`service_paths.ini` | PC 固有のパス。ユーザー名などを含む場合がある |
| `usage_stats.json`、ログ、設定バックアップ | 使用量、診断、機密設定を含む場合がある |

原作のセーブはさらに別です。バックアップでは現行の英語 ID と旧中国語名のフォルダーを両方保持します。意味検索の 50,000 件上限は正本履歴を削除しません。

認証ファイルのアクセス権は暗号化ではありません。キーの表示・非表示は画面上の見え方を変えるだけです。プラグイン設定にもキーの下書きが残る場合があります。

## PC 外へ送られるもの

選んだクラウド・中継先へ要求の文脈と必要な認証を送ります。中継を使えば受信者が増えます。サービス切り替えやローカル履歴削除では、旧サービス側の保持データは削除されません。[OpenAI API のデータ管理](https://platform.openai.com/docs/guides/your-data)など、提供元の方針を確認してください。

ローカル ASR は通常処理後に一時 WAV を削除しますが、中断、書き出し、バックアップには残る場合があります。リモート URL に変更すればデータの受信先も変わります。11435／9880／9881 はローカル用ですが、同じアカウントのソフトウェアから隔離する境界ではありません。公開ポート転送をしないでください。

## バックアップと移設

ゲームとサービスを終了し、ゲーム側の設定・履歴・必要なログ、および SPP フォルダー全体を保存します。正本 WAL・状態、全プロファイル、新旧ファイル、認証、人格、意味キャッシュ、モデル、参考音声を含めてください。外部 GPT-SoVITS／Fun-ASR の環境・重みも別途保存または再導入します。Dashboard のバックアップが全ファイルを含むとは限りません。

[新フォルダーへの展開と取り込み](UPGRADE.md)に従います。戻すときは対応するプログラムと更新前の全データを復元します。別 PC ではパスを直し、必要に応じて Python 仮想環境を再作成し、ゲーム・Steam の識別を再確認します。古い台帳だけでは新セッションの本人確認になりません。

## 共有と削除

問題報告前に API Key、Bearer token、個人識別情報、私的会話、機密パスを伏せてください。漏れたキーは投稿削除だけに頼らず無効化します。

無効化だけならサービスを止めて DLL を外し、データは保持できます。完全に消す場合は、不要な自分の実行データ・設定・履歴・バックアップ・書き出しも対象にします。プラグインの削除だけで、それらやサービス側データが消えるわけではありません。

公開 manifest は記録された内容・ハッシュや既知の個人ファイル混入を確認するもので、完全なバイナリ監査ではありません。過去の検証結果は記載された日付と範囲に限られます。
