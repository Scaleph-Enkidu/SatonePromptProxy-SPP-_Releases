# 更新後の確認項目

修正時の検証では Go のトップレベルテスト 666 件が成功、9 件がスキップ、EXE ペア試験 5 件と C# アサーション 1,548 件が成功しました。封入時にはソース識別情報、バイナリ、各ファイルの SHA-256、三言語のオフラインリンク、展開後の起動を確認します。今回、実ゲーム・マイク・外部モデルの新たな受け入れ試験は実施していません。過去の N15 の実機結果を本版の結果とは扱いません。大規模履歴の起動遅延と報告されたフレーム低下は引き続き調査中です。

## N15 修正

- 旧 CFG を更新し、Relaxed を `752,50,51` にします。
- 気楽な話題を 3 往復以上続けて `[Relaxed]` を出し、`[Satone14/动画] 整轮回复动作` に id:752／id:50／id:51 が出ることを確認します。256/751/753/755/52 やコップ残留があってはいけません。
- 任意で設定を保存し、`PreferStableConversationPoses=false` で標準プールを試して元に戻します。過去の実機証拠はホワイトリスト 2 回（id:50／id:752）で、標準プールは静的確認のみです。
- ログに `Loading [AIChat Remake 1.18.30]` が出ることを確認します。

## 回帰の抜き取り確認

- SPP の移動・再起動後も会話を続け、全要求が 409 で字幕だけになる状態が再発しないか確認します。
- 折り畳み矢印、下位メニュー、旧記憶取り込み、プロファイル見出し、長いパス欄を確認します。
- 感情表示を切り替え、履歴時刻前のタグを確認します。
- 自己エコー抑制、開始挨拶、原作のお菓子台詞の履歴を確認します。
- 中国語・English・日本語を選び、UI／字幕の選択を確認します。文字と音声は別に試し、UI 翻訳を全言語の声の合格としません。

動作、原作アニメーション抑止、`[VoiceCall/Echo] suppressed`、`[TTS]` のログを残します。報告前にキーと私的会話を除いてください。

今回のリリースは、記憶取り込み、音声エコー除去、終了時の後処理、日付による検索の計 9 件の修正をまとめています。AIChat と SPP の両方を更新してください。三言語の説明とパッケージ内の入口も更新しました。

取り込み失敗後の再試行、3 プロファイルと要約、繰り返された原作台詞のエコー除去、遅延 ASR、日付検索、ゲーム終了後の管理対象プロセスの終了を確認してください。
