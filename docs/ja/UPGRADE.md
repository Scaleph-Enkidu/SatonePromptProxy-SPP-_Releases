# 更新とロールバック

[ホーム](README.md) · [導入](INSTALL.md) · [バックアップ範囲](DATA_AND_PRIVACY.md)

**AIChat 1.18.30 + SPP 5.10.10**。 今回のリリースは、記憶取り込み、音声エコー除去、終了時の後処理、日付による検索の計 9 件の修正をまとめています。AIChat と SPP の両方を更新してください。三言語の説明とパッケージ内の入口も更新しました。

## 1. 変更前のバックアップ

ゲーム、SPP、関連する音声サービスを終了します。`local_v1`、`memory_profiles`、設定、認証、人格、旧形式ファイルを含む**旧 SPP 実行フォルダー全体**をコピーします。ゲームの `BepInEx\config` と現在の AIChat DLL／PDB も保存し、DLL のコピーは `plugins` の外へ置きます。

## 2. 新しい SPP フォルダーへ展開して取り込む

新しい SPP を別フォルダーへ展開します。ゲーム内の AIChat DLL／PDB は新しい組み合わせに置き換え、重複を残しません。ゲームと新 SPP を起動し、SPP・人格記憶の設定で旧版記憶の引き継ぎを選び、**旧 SPP フォルダーの絶対パス**を指定します。旧側は読み取り、取り込み先はバックアップされます。完了後に対象プロファイルと履歴を確認し、動作確認までは旧バックアップを保持します。

新しい SPP の EXE パスと外部 TTS／ASR／モデルのパスを確認してください。フォルダーの移動だけで記憶が自動移行するわけではありません。個人設定を例示ファイルで一括上書きしないでください。[移設ガイド](PORTABLE_DEPLOYMENT.md)も参照してください。

## 3. N15 用のアニメーション設定更新

N15 は Relaxed からコップ・お茶の動作 **256,751,753,755,52** を外します。BepInEx は既存 CFG を保持するため、DLL の交換だけでは不足します。

`BepInEx\config\com.username.chillaimod.cfg` の対象部分だけを変更する方法を推奨します。

```text
Relaxed=256,751,753,755,52
```

変更後：

```text
Relaxed=752,50,51
```

`StablePoseOverrides` の Relaxed 部分だけを変え、他の項目を残して保存し、ゲームを再起動します。別の方法として、バックアップ後に **`com.username.chillaimod.cfg` だけ**を削除して再生成できます。ただしキー操作、API 設定、しきい値、パス、感情表示などが初期化されるので、SPP パスを含めて再設定してください。SPP の記憶は消えません。

この設定更新のために `BepInEx.cfg`、`BepInEx/core`、`AIChatSatoneUX.history`、`SatoneInputHistory.v2.jsonl`、`AIChat.spp-*.json`、旧記憶フォルダーを削除しないでください。

## 4. 確認と復元

`BepInEx\LogOutput.log` の `Loading [AIChat Remake 1.18.30]`、F9 の接続・パス、Dashboard の取り込んだ履歴を確認します。気楽な話題を数回話し、修正された経路でコップが残らないことを確認してください。[パッケージ確認項目](PACKAGE_CHECKLIST.md)には、実機確認済みのホワイトリスト経路と、従来は静的確認のみだった標準プールの違いを記載しています。

ロールバック時はサービスを停止し、対応する旧プログラム**と更新前の全データ**を戻します。新しい記録を旧版が完全に理解できる保証はありません。文書改訂だけではデータ移行は発生しません。
