# AIChat v1.16.65 SPP v5.8.42

[← 履歴一覧](../RELEASE_ARCHIVE.md)

> 過去の公開記録です。配布状況・試験範囲は当時のもので、現行の導入には現在の手順を使ってください。

2026-09-30 の CP21 配布で、前回は 1.16.23＋5.8.26 でした。CP19-1 の推論強度・代替処理、CP20 の進行に応じた物語知識、CP21 の原作台詞タイムライン、吹き出し・文字サイズ・単行入力・サイズ変更ハンドル等を含みます。

Meta はゲームセッションごとに再演でき、起動時は第 1 段階から始まります。同一セッションのリセットには新しい冪等エンドポイントと原子的書き込みを使いました。当時の記録は最初の結末で画面乱れを維持し、その後の完了で通常終了する永続的な結末判定を説明しています。現在のセッション規則は[現行 Meta 説明](../systems/META.md)を参照してください。演出履歴はそのセッション中に残し、次回ログインで消し、通常会話は保持します。5.8.41 以前の段階記録も再生でき、新たな `recovery_required` を出しません。

当時はバックアップ後に対応するプログラムを交換し、設定・人格・記憶を保持しました。現行は [UPGRADE](../UPGRADE.md) に従ってください。当時残した旧安定版は後に撤去されています。[履歴](../RELEASE_ARCHIVE.md)を参照してください。

F10 の独立 SatoneStateCatalog を同時に公開し、現在の外観 ID と説明を `BepInEx/config/SatoneStateCatalog` に記録できるようにしました。セーブ変更や解放は行いません。

対応 CI workflow run のないローカル実機構築です。AIChat はビルドエラー 0、6 テストプロジェクト成功。SPP は go vet 正常で、既知の環境失敗 5 件（ASR 1、Recall／Python 4）以外は成功しました。窓イベント・リセットは実プレイヤーの 470 commit セーブのコピーで確認しました。全機器の実 API・Unity・声の動作を確認したという意味ではありません。個人キー・データは含みません。
