# AIChat v1.17.0 SPP v5.9.0

[← 履歴一覧](../RELEASE_ARCHIVE.md)

> 過去の公開記録です。配布状況・試験範囲は当時のもので、現行の導入には現在の手順を使ってください。

2026-10-01 の正式な組み合わせです。ユーザーはローカル試験の完了を確認しましたが、全機器・サービス・声を網羅していません。

文書改訂 1 は、単独で読める README・導入・変更履歴を追加し、プログラム・モデルを変えていません。既存ユーザーの実行更新は不要です。元 INSTALL 添付は元のバイト列のまま残し、改訂説明を docs_r1 ZIP に入れました。モデル URL・ハッシュは不変です。

文字・キーワード検索を旧 Python embedding から独立させ、マイクなしでも文字入力できます。任意の E5 small int8 と Windows x64 ORT CPU 1.30.0 は別配布・標準無効です。不足・破損・処理中・失敗ではキーワードへ戻り、ターン確定の必須依存にしません。

主セット約 11 MB、任意モデル約 94 MB で、互換プログラム更新では検証済みモデルを再利用できます。完全な `models` を EXE の隣へ置き、停止後に Verify／Enable／Disable を実行します。初回検索が準備・ベクトル生成を開始し、プロファイル別状態を表示します。Recall 欄のない旧 Dashboard はローカル API を使えました。

検索は受理され実際に提示した交流を対象にします。旧 DB を保持し、意味検索は最新 50,000 件、キーワードは全履歴、正本は削除しません。復旧で確定済み返答を再生成したり、関係・記憶効果を二重適用したりしません。導入を文字・ONNX・TTS・ASR の 4 段階に整理しました。Neutral は付属し、音声環境・重みは外部です。私有開発庫の個別 ZIP は追加必須ではなく、Source code ZIP もインストーラーではありません。

当時は全サービス停止・バックアップ後にプログラムとツールを交換し、認証、`local_v1`、全 `memory_profiles`、独自人格、モデル、`semantic_recall_v1`、音声を残す案内でした。実行フォルダー削除や例での個人設定上書きは避けます。全体の復元には対応する旧プログラムと更新前データが必要で、ONNX だけの停止は専用ツールを使います。現在は [UPGRADE](../UPGRADE.md) に従ってください。

検証は D 第 2 回の後端 14・クライアント 9 項目、実展開・上書きの 11 分岐が成功しました。実 ONNX の合成検索は正例 Top1 12/12、qualified 10/12、負例 qualified 0/3 で、実ユーザーの毎回成功を保証しません。20 ms サンプリングで合成実形式 WAL 5 万件の起動は約 495 秒、全処理ピーク 943,693,824 B でした。worker＋ベクトルのみの 350 MB 基準は 332,283,904 B で、SPP 全体の上限ではありません。大 WAL は遅いままで、全クリーン環境・提供元・声の合格は主張していません。API は実料金に従い、利用枠は付属しません。
