# 好感度と関係の計算

[システムの説明一覧](../README.md#systems) · AIChat 1.18.28 + SPP 5.10.8

表示される好感度は、**AI との会話で形成した関係値**と、**原作での経験による親しさの加算値**を合わせたものです。両者は別々に保存され、原作の加算が AI 関係の 4 項目を書き換えることはありません。

## AI 関係値

| 項目 | 主な意味 | 重み |
| --- | --- | ---: |
| Affection（A） | 個人的な好感、意味のある共有体験 | 50% |
| Trust（T） | 誠実さ、信頼性、拒否や境界の尊重 | 20% |
| Comfort（C） | 自然で安心でき、圧力の少ない交流 | 20% |
| Openness（O） | 私的な考えを話す意欲と、それが尊重されること | 10% |

各項目は 0～100 で、小数部分の進捗も保持します。

```text
F = 0.50 × A + 0.20 × T + 0.20 × C + 0.10 × O
```

新規の記憶 1・記憶 2 は標準で 4 項目とも 10、F=10 です。記憶 3 は最大好感度のテスト用プリセットが標準で有効になり、すべて 100 です。プリセットを無効にした場合や既存のプロファイルでは、実際の保存状態が使われます。更新時に関係を初期化する必要はありません。

変化は **0.05** 単位で蓄積します。例えば A=10、小数進捗 0.90 に +0.15 が加わると、A=11、残り 0.05 になります。表示には重み付けと丸めが入るため、小さな変化はすぐには見えないことがあります。

通常更新では各項目の変化が **−0.50～+0.30**、正に増える項目は最大 2 つ、増加合計は **+0.30** までです。重要な出来事では、標準の項目別絶対変化上限が 2、増加合計が **+2.00** です。これは各項目の制限であり、表示好感度が毎回その数だけ増減するという意味ではありません。繰り返す圧力には[別の規則](BOUNDARIES.md)があります。

単なる事実確認では長期的な関係が変わらないこともあります。甘えた振る舞いや軽い誘惑、依頼に応じてもらっただけでは加点されません。尊重、信頼できる行動、自発的な打ち明け話への反応、意味のある共有体験が重視されます。

`Curious` で本当に知りたいことを質問した後、プレイヤーが次の発言で関連する具体的な回答をすると、A と C に各 +0.05 の候補報酬が生じます。判定と合計上限は引き続き適用されます。同じ質問への二重加点や、直近 20 件の確認済み交流内で同じ話題への繰り返し加点はできません。感情タグ、疑問符、回答の長さだけでは証拠になりません。

## 原作の加算値

台帳には、確認済みの完了作業時間とメインストーリーの章が記録されます。H は基準値を差し引いた完了作業時間、N は加算対象となった異なる章の数です。

```text
W = 40 × ln(1 + H / 18) / ln(4)
S = N × 5/9
L = W + S
B = L                                  （L ≤ 60）
B = 60 + 10 × (1 − exp(−(L − 60) / 40)) （L > 60）
表示好感度 = round(min(100, max(0, F + B)))
```

H はゲームから同期された完了作業時間で、起動時間の合計ではありません。同じ章を再生しても重複加算されず、基準値以前に除外された部分も再加算されません。現在の規則では、対象となる各章の寄与は 5/9 です。

H=54、N=36 なら W=40、S=20、B=60 となり、F=10 なら表示は 70 です。これは計算例で、クリア済みセーブが必ず同じ値になるという意味ではありません。L が 60 を超えると増加が緩やかになり、B は 70 に近づきます。最終表示は 100 が上限です。

加算には、有効なゲームの識別情報、現在のセッションでの同期、プロファイルの原作加算設定が必要です。未同期・識別不能・設定無効の場合は F だけが表示されることがあります。表示が上がっても、AI 関係ファイルに同じ報酬が書かれたわけではありません。

## 関係段階

段階は丸める前の値で判断します。原作加算を適用した後、日常的な親しさには加算後の段階を使えます。

| 値 | 識別名 | 意味 |
| --- | --- | --- |
| 0 ≤ 値 < 20 | distant | 距離がある |
| 20 ≤ 値 < 40 | acquaintance | 知り合い |
| 40 ≤ 値 < 60 | familiar | 親しみがある |
| 60 ≤ 値 < 80 | close | 親しい |
| 80 ≤ 値 < 95 | very_close | とても親しい |
| 95 ≤ 値 ≤ 100 | intimate | 非常に親密 |

**好感度が高くても断ることはあります。** その時の気分、未解決の対立、明確な境界が反応に影響します。私的・親密な依頼には元の AI 信頼度や自己開示などの条件も必要で、原作加算だけでは解放されません。段階は一定の承諾確率を表すものではありません。

関係更新や表示の反映は主な返答より遅れる場合があります。定期的な照合は短期状態・対立・記録を整理するもので、4 項目を追加加点しません。[3 つの記憶プロファイル](MEMORY.md)はそれぞれ別の AI 関係を保持します。
