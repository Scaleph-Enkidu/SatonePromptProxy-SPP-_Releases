# チャット画面と履歴

[システムの説明一覧](../README.md#systems) · AIChat 1.18.30 + SPP 5.10.10

**F9** で AIChat を開きます。設定とチャットは別の領域で、履歴、入力欄、送信、音声操作も分かれています。現在の UI は中国語・英語・日本語に対応しています。利用する言語を設定してください。古い説明や画面例には中国語表記が残る場合があります。

## 入力と履歴

Enter で送信、Shift+Enter で改行します。F8 と音声操作は[音声入力](VOICE_INPUT.md)を参照してください。ストーリー再生、通信断、未完了のターンなどによる入力制限は引き続き適用されます。

標準の履歴表示は**最近の 50 発言**です。50 往復でも、保存上限でもありません。既存設定で別の件数を指定していれば、それが残る場合があります。原作台詞と AI 交流には出典があり、画面履歴、完全な保存記録、モデルに渡す文脈は同じ一覧ではありません。

画面履歴は `BepInEx/config/AIChatSatoneUX.history` にあり、SPP の全会話・記憶とは別です。このファイルを消しても、全プロファイルやサービス側のデータを削除したことにはなりません。

## 背景の設定

UI・動作設定には、ウィンドウ背景とチャット履歴背景の別々の調整があります。名称が透明度でも、値は **0.00 が完全透明、1.00 が完全不透明**です。背景を透明にしても文字、枠、ボタンがすべて消えるわけではありません。履歴背景の色を入力欄や設定領域まで一面に適用するものでもありません。

チャット背景色のカスタマイズでは R/G/B（0～255）と明度（0～100%）を調整できます。明度 0% は黒、100% は白で、可能な範囲で色相・彩度を保ちつつ RGB も更新します。別の透明度設定やゲーム全体のフィルターではありません。

ドラッグでプレビューし、保存・適用で永続化します。変更を破棄すると保存済みの値に戻り、背景色だけを標準に戻すこともできます。更新後に古い値が残る場合は、全セーブを削除せず設定を確認してください。[保存場所](../DATA_AND_PRIVACY.md)も参照してください。
