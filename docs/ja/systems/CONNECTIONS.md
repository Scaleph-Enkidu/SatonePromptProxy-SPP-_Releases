# モデル接続と切り替え

[システムの説明一覧](../README.md#systems) · AIChat 1.18.30 + SPP 5.10.10

接続にはサービス種別、接続先、モデル名、認証情報が含まれます。会話が使うのは適用済みの 1 接続で、編集途中の内容が自動的に有効になるわけではありません。

## 接続できるサービス

OpenAI、DeepSeek、Claude、Gemini、設定可能な中継サービス、ローカル Ollama の経路があります。使えるモデルはサービスとアカウントに依存し、標準名は編集可能な例です。クラウド API には API 権限と利用枠が必要です。中継先の URL・認証・モデル名は、その API に合わせます。Ollama は自分でサービスとモデルを用意し、クラウド文字チャットとは別に RAM・VRAM が必要です。

## 保存と適用

F9 の設定 → LLM で接続を編集し、サービス・モデルを選んで保存・適用します。切り替え成功の表示と現在の適用済みサービスを確認してください。選択欄だけでは確定できません。処理中・結果不明のターンは調整・復旧手順に従います。すでに開始した要求は、開始時の接続条件を保ちます。

接続テストは実際にサービスへアクセスし、使用量が発生する場合があります。成功しても、その瞬間の到達確認であり、後の全要求・形式・モデル・残高を保証しません。

同じプロファイルならサービス変更後もローカル履歴・記憶・関係を使えます。話し方や解釈が変わっても、保存データが消えたとは限りません。旧サービス側の保持データは自動削除されません。キーは接続別に保存されるため、設定・認証ファイルを保護してください。[プライバシー](../DATA_AND_PRIVACY.md)と[費用](../API_COST.md)も参照してください。

## 推論の強度

Auto、None、Low、Medium、High、Max は `auto / none / low / medium / high / max` に対応します。手動指定は対応する OpenAI・DeepSeek 接続向けで、その他は Auto を使います。実際のパラメーターはサービス・モデルの能力に対応付けられ、全モデル共通ではありません。強くすると待ち時間や使用量が増える場合がありますが、人格再現や形式が必ず改善するわけではありません。非対応の場合は明示された状態・エラーに従い、代替動作を元の指定が有効になった証拠としないでください。
