# 記憶とプロファイル

[システムの説明一覧](../README.md#systems) · AIChat 1.18.28 + SPP 5.10.8

聡音は過去の会話すべてを毎回モデルに送るわけではありません。記録をローカルに残し、各ターンで最近の交流、整理済みの記憶、関連する検索結果を組み合わせます。

## 3 つの独立したプロファイル

記憶 1・2・3 は、会話、長期記憶、AI との関係を別々に保存します。切り替えると、そのプロファイルの経験を使います。人格ファイルは共有され、同じプロファイルの記憶と関係を保ちながらサービスやモデルを変更できます。ただし、話し方や理解力はモデルで変わります。記憶 3 の標準の最大好感度テスト設定は、普通の新規プロファイルとは異なります。[好感度](AFFECTION.md)を参照してください。

| 内容 | 会話での役割 |
| --- | --- |
| 最近の原文 | 現在の話題を継続する |
| 長期記憶の要約 | 古い交流から重要な情報を整理して保持する |
| 完全なローカル記録と索引 | 必要なときに検索する。毎回すべては送らない |

画面に表示する最近の 50 発言は保存上限ではありません。要約が細部を落としたり、検索が見つけられなかったりすることもあります。ローカルにある情報を、今回のモデルが必ず知っているとは限りません。

## 自動整理

標準の整理しきい値は **32,000 token**、最近の原文を残す目標は約 **12,000 token** です。token はモデルの処理単位で、文字数とは異なります。推定リクエスト予算と最近のメッセージ数も考慮し、上限に近ければ早めに整理する場合があります。

この数値は全モデル共通のコンテキスト上限でも、各リクエストの正確な残量でもありません。人格、入力、要約、その他の文脈も容量を使い、接続ごとの予算が整理時期に影響します。

古い交流を要約しても元の記録は保持します。生成済みでも未表示・未再生の内容を、すでに伝えた発言として記憶に入れません。整理に失敗した場合は履歴を残し、成功したことにはしません。それでも予算を超える場合、そのターンを続行できないことがあります。

## 保存と更新

ローカル会話の正本は `local_v1` にあり、プロファイルのデータは `memory_profiles` などにも保存されます。旧版の JSON・テキスト・データベースが残ることもあります。古いファイルが更新されないだけで、新しい会話が保存されていないとは判断できません。

ゲームとサービスを終了し、SPP の個人用実行フォルダー全体とゲーム側の設定・履歴をバックアップしてください。正本記録は削除可能なキャッシュではありません。[データとバックアップ](../DATA_AND_PRIVACY.md)、[更新手順](../UPGRADE.md)を参照してください。
