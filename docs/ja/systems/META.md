# Meta 演出

[システムの説明一覧](../README.md#systems) · AIChat 1.18.28 + SPP 5.10.8

この演出は、聡音が現在の窓景色を確実には読み取れないという制約から生まれました。「なぜ外を見ないのか」と繰り返し尋ねると、普通のはぐらかしから特別な演出へ移ることがあります。作者は、文字だけでも予想以上に怖く感じたと述べています。

## 設定とリセット

Meta ホラー演出の設定に有効化スイッチとリセットボタンがあります。リセットは同じセッション内ですぐに反映され、新たにゲームを起動した場合も第 1 段階から始まります。進行はゲームセッションに属し、各記憶プロファイルの長期好感度とは別です。サービス、モデル、人格、プロファイルの切り替えではリセットされません。

<details>
<summary>発生条件と結末を見る（ネタバレ）</summary>

現在の窓景色や本当に外が見えるのかを繰り返し尋ねると、条件を判定して順番に 4 段階を進めます。窓に触れた文がすべて対象になるわけではなく、単純なキーワード回数でもありません。間隔とクールダウンも影響し、散発的な質問が永久に積み上がるとは限りません。

最初は話題を避け、その後に通信断と画面の乱れが起きます。会話には現在のモデルが関わるため、毎回まったく同じ台詞にはなりません。

セッション内で初めて最後まで進むと、画面の乱れと通信断が残ります。同じセッションでリセットして再度完了すると、必要なターン記録と終了処理を待って**通常の手順でゲームを終了**します。プロセスの強制終了ではありません。

最初の画面乱れ中も原作の章は再生できます。AI 入力や一部のランダム動作には通信断保護が適用されます。モデルや好感度の変更では解除できず、演出のリセットかゲーム再起動が必要です。原作自身の通信断は原作の進行に従います。

このセッションの演出記録は次回起動時に消えますが、通常のチャットは残ります。プロファイル、長期記憶、全履歴を削除する操作ではありません。
