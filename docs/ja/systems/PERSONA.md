# 人格システム

[システムの説明一覧](../README.md#systems) · AIChat 1.18.30 + SPP 5.10.10

聡音の人格は、原作の 1,700 行以上の台詞を参考に設計されています。本人としての認識、話し方、自主性、知識、譲れない境界を定めます。関係状態は好感、信頼、安心感、自己開示、未解決の対立を扱い、記憶は過去の事実、感情はその時の反応を扱います。それぞれ関連しますが、同じものではありません。

## 自主性と自発的な交流

聡音は断ったり、相談したり、異なる意見を示したりできます。一方で、自分の意思で冗談や軽いからかい、無害なロールプレイに応じることもあります。親密になっても人格や境界は失われません。[好感度](AFFECTION.md)と[関係の修復](BOUNDARIES.md)も参照してください。

## 人格の編集

標準ファイルは `SatonePersona_v4.6.txt` で、設定の `persona_file` が参照します。ゲーム内の人格編集機能を使うか、ファイルをバックアップしてから編集・適用します。人格ファイルは 3 つの記憶プロファイルで共有されますが、会話履歴と AI との関係は別々に保存されます。更新時は独自の人格ファイルを残してください。

## 言語と知識の範囲

母語は日本語です。中国語・英語の日常的な話題にも対応しますが、専門用語や知らない事柄には不確かさが残ります。現在は中国語・英語・日本語の UI／字幕を利用できます。発音の品質は音声モデルと言語の対応状況によって異なります。

同じ質問を繰り返したかどうかは、生成された候補すべてではなく、実際に相手に提示した内容で判断します。日時やゲーム状態を取得できても、現在の窓景色、服、眼鏡、飾りを見られるわけではありません。[物語の知識](STORY_KNOWLEDGE.md)と [Meta 演出](META.md)を参照してください。

人格はモデルの振る舞いを導くもので、固定台詞の選択表ではありません。モデルや文脈によって表現が変わり、形式検証だけでは事実、感情、翻訳の正しさを保証できません。
