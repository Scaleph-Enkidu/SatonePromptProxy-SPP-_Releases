# サービスの起動と管理

[システムの説明一覧](../README.md#systems) · AIChat 1.18.30 + SPP 5.10.10

文字チャット、意味検索、音声合成、音声認識は段階的に導入します。後のサービスがなくても、設定済みの文字チャットは利用できます。ウィンドウが開いているだけでは全モデルの準備完了を意味しません。

| サービス | 標準ローカルポート | 役割 |
| --- | ---: | --- |
| SPP | 11435 | 会話代理、人格、記憶、関係、状態表示、TTS／ASR 転送 |
| GPT-SoVITS API | 9880 | 聡音の音声合成 |
| Fun-ASR | 9881 | マイクの音声認識 |
| ONNX worker | 別のネットワークサービスの起動は不要 | SPP が管理する CPU 意味検索 |

ゲームの共通音声 URL は `http://127.0.0.1:11435` にします。ローカル利用でルーターのポート開放は不要です。

| ツール | 用途 |
| --- | --- |
| `SatonePromptProxy.exe` | 導入手順で使う直接起動 |
| `Start_Text_Chat.bat` | 同じ SPP を起動する便利な入口 |
| `Set_GPTSoVITS_RunApi_Path.bat` | 準備済み TTS 起動スクリプトの場所を保存 |
| `Start_AIChat_Services.bat` | SPP と設定済み GPT-SoVITS を起動。環境や重みは導入しない |
| `Stop_SatonePromptProxy.bat` | SPP を停止。モデルや記憶は削除しない |
| ゲーム内の自動起動・終了 | 設定したサービスを管理。保存後に実際の動作を確認 |

GPT-SoVITS 自体の `run_api.bat` で起動しても構いません。手動起動とプラグイン起動では管理元が異なるため、ゲーム終了後に各状態を確認してください。自動終了設定は、全 Python プロセスの終了を意味しません。

## 導入済み・起動中・準備完了

ファイル不足、読み込み中、現在のヘルスチェック成功は別の状態です。TTS は実際に再生できる音声、ASR は実際の発言認識で確認します。重複起動はポート競合やモデルの二重読み込みにつながります。繰り返しスクリプトを開く前に既存プロセスと最初のエラー・完全なパスを確認してください。

Fun-ASR の再起動状態は個別に記録します。結果が不明なら現在のサービス状態を確認し、通信断だけで成功と判断しません。参考音声の詳細な異常は TTS の理由表示を確認します。

更新時はゲーム・サービスを終了して個人データをバックアップし、[新しいフォルダーへの展開と取り込み](../UPGRADE.md)に従います。設定、認証、記憶、関係、人格、モデル、音声を保持し、互換性のあるモデルは再利用できます。ONNX の設定ツールは SPP 停止後に実行します。[負荷](../HARDWARE.md)と[バックアップ範囲](../DATA_AND_PRIVACY.md)も参照してください。
