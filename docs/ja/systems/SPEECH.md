# 音声と字幕

[システムの説明一覧](../README.md#systems) · AIChat 1.18.30 + SPP 5.10.10

AIChat が字幕表示と音声再生を担当し、SPP が返答を区切って合成要求を転送し、GPT-SoVITS がテキスト・声の重み・参考音声から音を生成します。現在は中国語・英語・日本語の UI／字幕に対応しています。ただし、導入した声が 3 言語すべてを自然に発音できるとは限りません。この手順の参考構成は日本語音声です。

## 区間ごとの対応

返答には感情と言語ごとの項目があり、提示前に検証します。従来の日本語音声・中国語字幕経路では、中国語の各項目は**句読点を含めて 41 文字**までです。これは中国語経路の説明であり、すべての言語表示に同じ上限があると主張するものではありません。区間ごとの再生で後続音声を先読みできます。対応する言語の区間は同じ意味を伝える必要がありますが、一文字ずつ一致する必要はありません。形式確認で翻訳の正しさは保証できません。

| 素材 | 役割 |
| --- | --- |
| 声の重み | 学習済みの声と対応モデル版を決める |
| 参考 WAV | 合成時の声質・調子の手本 |
| 参考台詞 | WAV 内で実際に発音された内容 |
| 感情設定 | 利用できる参考音声を選び、任意素材がなければ Neutral を使う |

パッケージには `mayuri-voice/refs/MAY_1158_Neutral.wav` が含まれますが、GPT-SoVITS 環境全体や声の重みは含みません。WAV があるだけで発声機能の導入完了とはなりません。開始時に 26 種の参考音声を揃える必要もありません。

TTS 設定の参考音声チェックと異常理由を開き、パス、ファイル、台詞、サービス状態を確認します。任意の感情音声がなければ Neutral に戻れますが、標準参考音声自体やバックエンドに問題があれば正常な音声は生成できません。ファイル検証とモデル読み込み・実際の再生成功は別です。

TTS なしでも文字チャットを使えます。導入後は短い文を合成し、ゲーム内でも再生を確認してください。中断時に記憶・関係へ使うのは確認済みの表示と再生完了した区間であり、未再生の候補すべてを聞いたことにはしません。[復旧](RECOVERY.md)、[導入](../INSTALL.md#stage-3)、[音声の詳細設定](../VOICE_SETUP.md)を参照してください。
