# 人格系统说明

[返回系统说明入口](../../README.md#系统设计与使用说明) · [好感度系统](好感度系统说明.md) · [边界与关系修复](边界与关系修复说明.md)

适用版本：**AIChat 1.17.1 + SPP 5.9.1**。说明更新：2026-10-01。

人格文件规定聪音是谁、如何表达、如何理解人与人的关系，以及哪些事情她愿意或不愿意做。为了还原原版性格，作者分析了原游戏 **1700 余句对话**，整理她的用词、语气和面对不同话题的反应。

## 人格、关系和记忆各管什么

| 内容 | 作用 |
| --- | --- |
| 人格 | 身份、性格、表达习惯、知识范围、自主性和核心边界 |
| 当前档案的关系 | 你们的亲近程度、信任、舒适、开放程度和未解决冲突 |
| 当前档案的记忆与剧情上下文 | 之前说过什么、已经共同经历什么、本轮有哪些相关事实 |
| 情绪 | 这段话当下如何表达，不等同于长期关系分数 |

她可以拒绝、协商、保留意见，也可以自愿开玩笑或做短暂表演。好感度会影响亲近程度，但不会让人格中的自主性和核心边界失效。想象和创作按聪音自己的活动理解，不要求她放弃原本身份。

## 默认人格与修改

当前默认人格文件是 SPP 目录中的 **`SatonePersona_v4.6.txt`**，实际使用位置由 `persona_file` 配置决定。界面提供人格编辑与应用操作；也可以在备份后修改实际使用的文件，再按界面流程应用。

人格由三套档案共用，修改会影响三个档案之后的回应；各档案的聊天、记忆和关系仍分别保存。不要为了改说话风格删除整个 SPP 目录或覆盖自己的记忆文件。

升级会区分原封不动的默认人格与玩家自行修改的内容，不应把自定义文件强行当作默认文件替换。发现更新后仍在使用自己的旧人设时，先检查当前选择的文件与内容。

## 表达与知识范围

默认设定以日语为母语，也具备日常中文、英语交流能力；生僻术语或不熟悉的语言需要保留不确定性。重复提问会结合之前实际回答的内容处理，不能把尚未显示或听到的答案算成已经答过。

系统可以提供日期、时间等相关环境信息，但当前没有完整接入窗景、服装和摆件的外观说明。她不能仅凭玩家问起就可靠描述屏幕上实际是什么；见[剧情知识与共同经历](剧情知识与共同经历说明.md)与[Meta 演出](Meta演出系统说明.md)。

人格属于模型的行为指引，不是逐句固定台词。不同模型对细节的执行程度可能不同，也不能保证每次翻译、事实判断或情绪选择都正确。字幕分段等机器格式由程序另外校验，通常不需要为了改变性格去修改格式规则。
