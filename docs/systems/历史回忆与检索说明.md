# 历史回忆与检索说明

[返回系统说明入口](../../README.md#系统设计与使用说明) · [记忆与档案](记忆与档案系统说明.md) · [ONNX 安装](../ONNX_SETUP.zh-CN.md)

适用版本：**AIChat 1.17.1 + SPP 5.9.1**。说明更新：2026-10-01。

检索帮助聪音在当前话题需要时查找旧交流。它从当前档案的记录中挑选相关内容，再提供给聊天模型；不会让模型每轮阅读所有旧聊天。

## 两种回忆方式

| 方式 | 怎么查找 | 安装要求 |
| --- | --- | --- |
| 关键词回忆 | 根据文字、关键词及中日文片段查找相近记录 | 已内置，文字聊天不需要 Python |
| 语义回忆 | 通过本地向量模型比较意思，帮助找到换了一种说法的旧话题 | 另装约 94 MB ONNX 组件并主动启用，在本机 CPU 运行 |

例如以前说“最近在练钢琴”，之后问“上回提到的乐器练得怎么样”，语义检索可能比只看相同关键词更容易找到相关交流。是否命中仍取决于记录、措辞、模型和筛选条件。

## 哪些历史会参与检索

关键词索引覆盖完整可用历史。语义投影最多保留**最新 50,000 条已交流记录**，超过时较早内容仍保留在权威存档，关键词仍可检索；这不是删除旧记忆的上限，也不是聊天窗口的 50 句限制。

当前档案单独构建和查询索引，不把其他档案的经历直接混入。新版本会按实际展示的文字、实际完成的语音片段确认聪音已交流的内容；尚未呈现的候选答案不能冒充已经说过的话。

## 为什么检索到了，也不一定会说出来

检索结果会经过分数、语义领先程度和原始记录复核，再决定是否带入本轮上下文。相似度不是事实正确概率，系统会保守筛选，避免把相似但不同的经历混在一起。

很长的记录在语义模型输入中还会截断，关键词检索仍可使用全文。即使成功带入历史，聊天模型也可能遗漏、误解或没有在这句回复中提及它，不能把相似度当作保证。

## 缺组件、加载中或失败时

ONNX 组件默认不启用。缺少模型、文件校验失败、加载失败、忙碌或超时时，可以继续使用关键词回忆，不要求等待语义组件才能完成文字聊天。

第一次启用或切换档案时需要暖机和构建；状态中的 loading、building、ready 等是不同阶段。语义缓存位于 `semantic_recall_v1`，可以按维护流程重建，但包含私人交流相关数据，仍需保护。它与不能随意删除的 `local_v1` 权威存档不同。

安装和启停见[ONNX 设置](../ONNX_SETUP.zh-CN.md)，大存档耗时与内存见[运行开销](../HARDWARE.zh-CN.md)。
