# 情绪系统说明

[返回系统说明入口](../../README.md#系统设计与使用说明) · [语音与字幕](语音与字幕系统说明.md) · [好感度系统](好感度系统说明.md)

适用版本：**AIChat 1.17.1 + SPP 5.9.1**。说明更新：2026-10-01。

情绪描述聪音这一段话的表达状态，用于界面标记和语音参考配置。它与长期好感度分别处理：一次开心不自动加分，一次疲倦也不代表关系变差。

## 26 种情绪及界面分组

| 界面分组 | 情绪标签 | 作用 |
| --- | --- | --- |
| 正向，红色 | Happy、Excited、Relaxed、Affectionate、Playful、Teasing、Smug | 愉快、兴奋、放松、亲昵、玩笑等表达 |
| 负向，蓝色 | Sad、Crying、Pouting、Angry、Chiding、Nervous、Afraid、Shocked、Mocking、Sarcastic、Disagree | 难过、不满、紧张、害怕、责备、拒绝等表达 |
| 中性或混合，黄色 | Neutral、Tired、Sleepy、Confused、Curious、Think、Surprised、Shy | 疲倦、困倦、疑惑、思考、惊讶、害羞等表达 |

颜色只是 UI 分组，不改变标签本身，也不额外决定关系分数。特殊失联状态可能显示“未知”，不能把它理解为新增情绪。

## 相近的情绪为什么分开

- **Happy / Relaxed / Excited**：明显开心、低强度的舒适放松、较强的兴奋期待，表达强度不同。
- **Surprised / Shocked**：一般惊讶与受到冲击不同。
- **Teasing / Mocking / Sarcastic**：亲近的逗弄、嘲弄和讽刺不是同一种态度。
- **Angry / Chiding**：生气与责备可以有不同表达方式。
- **Curious / Think**：想进一步了解，与正在思考不同。Curious 不能作为所有“投入聊天”的通用标签。
- **Tired / Sleepy**：疲劳与困得想睡觉分别处理。

高好感度不强制使用正向情绪，也没有每几轮必须开心一次的配额。情绪应当符合当前话题、心情和表达，而不是轮换装饰。

## 情绪如何影响声音

回复可以按段分别带有情绪。SPP 将该标签用于对应语音参考配置；缺少可用情绪参考时回退 Neutral。能显示 26 种标签，不等于必须下载 26 份音频才能聊天，也不保证每种标签都有同等明显的声音差异。

声音还受模型权重、参考音频、台词和合成环境影响。参考音频检查与设置见[语音与字幕系统](语音与字幕系统说明.md)。
