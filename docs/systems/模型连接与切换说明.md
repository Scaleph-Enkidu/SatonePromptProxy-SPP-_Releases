# 模型连接与切换说明

[返回系统说明入口](../../README.md#系统设计与使用说明) · [安装配置](../INSTALL.zh-CN.md#stage-1) · [费用说明](../API_COST.zh-CN.md)

适用版本：**AIChat 1.17.1 + SPP 5.9.1**。说明更新：2026-10-01。

“连接”包含服务类型、地址、模型名称和对应凭据。任一时刻使用一个已经应用的连接；编辑框中的草稿不等于当前聊天已经切换过去。

## 可以连接哪些类型

本版提供 OpenAI、DeepSeek、Claude、Gemini、可配置中转连接和本机 Ollama 路径。可用模型与权限由实际服务和账户决定，默认模型名只是可修改的示例，不能保证每个账户都能调用。

云端连接需要服务商 API 权限与额度。使用中转站时，地址、鉴权和模型名称按中转站的接口要求填写。本机 Ollama 需要自己准备服务和本地模型；本地模型的内存、显存开销另取决于模型，不包含在云端 API 文字聊天的低本机开销说明里。

## 保存与切换

在 F9 → 展开设置 → LLM 中编辑所用连接，选择服务和模型，再点击 **“保存并应用配置”**。成功状态显示 **“切换成功”**；失败或结果未确认时，应检查当前已应用服务，不能只依据选择框的位置判断。

有正在处理或状态待确认的回合时，切换需要服从当前请求的恢复与协调流程。已经开始的请求使用开始时确定的连接，不因后来修改草稿而悄悄换成另一套参数。

连接测试会实际访问服务，可能产生用量；一次可达测试只说明当时的探测结果，不保证之后所有请求、格式、模型和余额都可用。

## 切换后记忆会怎样

同一档案的本地历史、长期记忆和关系可以继续使用，不要求删除档案或重新安装。模型的措辞、理解和情绪判断可能改变，不能把这种变化等同于存档丢失。

切换服务不会自动删除旧服务端可能保留的数据；具体数据流见[隐私说明](../DATA_AND_PRIVACY.zh-CN.md)。API Key 分连接保存，应当保护配置与凭据文件，勿把完整文件发到公开 Issues。

## 思考强度

本版界面提供 **自动、None、Low、Medium、High、Max**，分别表示自动、关闭额外推理、低、中、高和最高强度，对应 `auto / none / low / medium / high / max`。手动强度用于支持的 OpenAI、DeepSeek 连接，其他服务使用自动选项。

这些档位会映射到具体供应商和模型能力，不是所有模型通用的相同参数。较高档位可能增加等待与用量，也不能保证角色还原或格式一定更好。遇到不支持的设置时，按明确的状态／错误处理，不能把回退结果当作原档位已经生效。
