# 聊天 API 与费用

[返回首页](README.md) · [四阶段安装](INSTALL.md)

适用配对：**AIChat 1.18.28 + SPP 5.10.8**，更新于 **2026-10-01**。云端聊天需要自己的服务账户、API Key 与可用额度；游戏、插件下载和 ChatGPT 网页订阅不包含本 Mod 的 OpenAI／DeepSeek API 用量。

## 价格和模型名称在哪里确认

界面的预填模型名称是可修改的示例，不是当前权限、价格或供应商可用性的保证。使用哪家服务，就到那家的模型与账单页面确认；第三方中转站按其实际条款和账单计算。

- OpenAI：[模型列表](https://developers.openai.com/api/docs/models)、[API 价格](https://developers.openai.com/api/docs/pricing)、[用量](https://platform.openai.com/usage)、[账户计费](https://platform.openai.com/settings/organization/billing/overview)。
- DeepSeek：[模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)。
- 其他所用供应商／中转站：它们自己的模型、账户权限、价格与账单页面。

价格、充值要求和汇率会变化，请以供应商实时页和最终账单为准；旧版本文档中的预算数字不能作为当前报价，也不是固定日费。

## 为什么不是“一句话固定多少钱”

API 通常按实际 token 和服务计费，不按玩家说了几句话收费。主聊天输入可能包含人格、规则、记忆、近期交流和当前问题；还可能产生关系更新、记忆整理、格式修复与重试等辅助请求。较长推理、更多上下文、缓存命中差异及多次请求会改变费用。

估算时将当天全部相关请求的用量加总，分别套用该服务当前的输入、缓存、输出与其他计费类别；不要把缓存用量重复加到总输入上，也不要只数屏幕显示的回答。

```text
单请求费用 = 各计费类别的用量 × 对应实时单价，再按计量单位换算
每轮平均费用 = 当天所有相关请求费用之和 ÷ 当天完成的对话轮数
估算可用天数 = 可用余额 ÷ (每轮平均费用 × 预计每天轮数)
```

这些公式不是费用上限。税费、汇率、供应商特殊模式或其他服务收费按实际账单处理。

## 怎么控制预算

先用少量对话观察供应商用量与计费页，再按自己的真实数据估算。用独立项目／Key 区分 Mod 的调用，使用供应商提供的提醒或支出控制，并确认它是提醒还是实际阻止继续消费。

SPP 的 `pricing` 是本地估算表，可能没有当前模型或保留旧单价；显示 0／未知不代表服务商没有扣费。手动维护时应按返回模型 ID 匹配当前供应商价格；修改本地表不会改变供应商扣费，也不会保证补算此前遗漏。最终以服务商账单为准。

## 本地回忆与语音的费用范围

内置关键词回忆与选装 ONNX 回忆在本机运行；下载或启停 ONNX 不会附送云端聊天额度。按本教程部署的 GPT-SoVITS 和 Fun-ASR 也在本机合成／识别，不调用 OpenAI 的收费语音接口；它们仍有本机资源和电力开销。改用远程语音服务时按实际服务收费与隐私条款判断。
