# 聊天界面与历史记录说明

[返回系统说明入口](../README.md#systems) · [记忆与档案](MEMORY.md) · [数据保存位置](../DATA_AND_PRIVACY.md)

适用版本：**AIChat 1.18.28 + SPP 5.10.8**。三语文档整理：2026-10-06；原测试数据仍按其记录日期理解。

按 **F9** 打开 AIChat 界面。控制台标题为 **“AIChat Remake控制台”**，上方设置区与下方聊天区分别保留分区；聊天区内还区分历史记录框、输入框、发送及语音操作区。

## 基本操作与历史范围

输入文字后按 Enter 发送，Shift + Enter 换行。F8 与语音按钮的作用见[语音输入说明](VOICE_INPUT.md)。剧情、失联或当前回合尚未处理完时，输入仍受当前状态限制。

历史记录顶部提示为 **“（历史记录仅显示最近50句对话）”**。这里的 50 句是默认窗口记录范围，不是 50 轮完整问答，也不是长期记忆或存档上限；旧配置中自行设置的其他条数可能继续保留。原版台词与 AI 交流有各自来源；完整本地记录与模型每轮实际上下文也不是同一份列表。

窗口历史文件是 `BepInEx/config/AIChatSatoneUX.history`，不等于 SPP 完整聊天与记忆。清除或移除窗口历史文件，不能被理解为已经清除所有档案和服务商数据。

## 两个背景透明度

在“界面与行为”中分别调整窗口背景与聊天框背景：

| 设置 | 范围与作用 |
| --- | --- |
| 背景透明度 | 0.00 为完全透明，1.00 为完全不透明，作用于窗口相关背景 |
| 聊天框背景透明度 | 0.00 为完全透明，1.00 为完全不透明，仅作用于历史记录框背景 |

虽然名称叫“透明度”，数值越大实际越不透明。设置背景透明不代表文字、按钮和边框也全部消失。聊天框背景不应把输入框、按钮和设置区一起染成一整块，原有分区保留。

## 自定义聊天背景颜色

展开 **“自定义聊天背景颜色”**，可以调整红色 R、绿色 G、蓝色 B 和明度四个条。RGB 显示范围为 0～255，明度为 0%～100%。

明度 0% 为黑，100% 为白；调整明度会同步更新 RGB，并尽量保留当前色相与饱和度。它不是另一个透明度开关，也不会给游戏画面整体加滤镜。

拖动可以预览，点击 **“保存并应用配置”** 后持久生效；放弃修改返回已保存设置，也可恢复默认聊天背景颜色。若升级后仍显示旧数值，先检查保留的个人配置，不必为了刷新颜色删除整个存档。
