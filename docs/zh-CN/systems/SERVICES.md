# 服务启动与进程管理说明

[返回系统说明入口](../README.md#systems) · [四阶段安装](../INSTALL.md) · [语音排错](../VOICE_SETUP.md)

适用版本：**AIChat 1.18.28 + SPP 5.10.8**。三语文档整理：2026-10-06；原测试数据仍按其记录日期理解。

文字聊天、语义回忆、聪音发音和玩家语音识别分阶段安装。后续服务缺失不应阻止已经配置好的文字聊天，也不能把打开一个窗口当作所有模型都已就绪。

## 各服务负责什么

| 服务 | 默认本机端口 | 职责 |
| --- | ---: | --- |
| SPP | 11435 | 聊天代理、人格、记忆、关系、状态页及 TTS／ASR 转发 |
| GPT-SoVITS API | 9880 | 聪音语音合成 |
| Fun-ASR | 9881 | 玩家麦克风识别 |
| ONNX 语义 worker | 不要求玩家另开网络服务 | 本地 CPU 历史语义检索，由 SPP 管理 |

游戏中的共用语音服务地址默认为 `http://127.0.0.1:11435`，由 SPP 转发到已配置的语音后端。服务只需本机访问，不要求路由器端口转发。

## 启动工具与自动启动

| 工具或设置 | 用途 |
| --- | --- |
| `SatonePromptProxy.exe` | 安装教程使用的直接启动方式 |
| `Start_Text_Chat.bat` | 启动同一个 SPP 的便捷入口，不另起一套不同的文字服务 |
| `Set_GPTSoVITS_RunApi_Path.bat` | 记录已准备好的 GPT-SoVITS 启动脚本位置 |
| `Start_AIChat_Services.bat` | 联动启动 SPP 与已配置的 GPT-SoVITS API，不负责安装环境和权重 |
| `Stop_SatonePromptProxy.bat` | 停止对应 SPP；不等于卸载模型和删除记忆 |
| 游戏设置中的自动启动／自动关闭选项 | 根据已配置路径和生命周期处理相应服务，需要保存并实际检查 |

GPT-SoVITS 也可直接按教程使用自己的 `run_api.bat`。手动启动的服务与插件联动启动的进程来源不同，退出游戏后要确认各自状态，不能把一个自动关闭选项理解为关闭电脑上所有 Python 进程。

## 区分安装、启动与就绪

未安装表示缺少所需组件；加载中表示还在准备；就绪表示当前状态检查通过。TTS 还要实际合成并听到声音，ASR 还要实际识别一段发言，才能确认链路工作。

重复启动可能导致端口占用和重复模型加载。报错时先确认原服务是否仍在运行，保留第一条错误与完整路径；不要不断双击启动脚本，再根据窗口数量猜测是否成功。

Fun-ASR 的重启状态会单独记录。重启结果未知时先核对服务当前状态，避免把网络断线直接当作重启已成功。参考音频的详细异常见 TTS 设置中的“异常原因”。

## 升级与退出

升级前退出游戏、SPP 和相关服务，备份个人运行数据，再按[升级指南](../UPGRADE.md)安装到新目录并导入。保留配置、连接凭据、记忆、关系、人格、模型和语音目录；模型组件可以按兼容情况复用。

ONNX 启停与安装工具要求停止 SPP 后执行，避免运行中修改配置。启动耗时、重复服务的资源影响与硬件边界见[运行开销](../HARDWARE.md)，备份范围见[数据与隐私](../DATA_AND_PRIVACY.md)。
