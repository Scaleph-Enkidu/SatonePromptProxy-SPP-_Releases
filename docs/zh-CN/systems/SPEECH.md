# 语音与字幕系统说明

[返回系统说明入口](../README.md#systems) · [语音安装与排错](../VOICE_SETUP.md) · [情绪系统](EMOTIONS.md)

适用版本：**AIChat 1.18.28 + SPP 5.10.8**。三语文档整理：2026-10-06；原测试数据仍按其记录日期理解。

本教程的参考配置由聪音用日语朗读。程序现已支持中文、英文、日文界面与字幕；具体发音能力仍取决于所选声线和模型。AIChat 负责游戏内展示和播放，SPP 处理回复分段与语音转发，GPT-SoVITS 根据日语文本、模型权重和参考音频生成声音。

## 文字、字幕和声音如何对应

原日语朗读／中文字幕路径中，模型回复按“情绪、日语、中文”组成语义段。程序检查字段、标签和分段后，把日语送去合成，中文用于字幕。这一中文路径每段中文字段限制为 **41 字符，包含标点**，不将它扩展为全部语言界面的统一上限；实际展示还会根据字幕规则处理。

语音与字幕按段推进，可以预取后续音频，减少段间等待。日语和中文在长度上不必逐字对应，主要要求同一段表达相同意思；翻译本身仍可能出错，格式检查不能证明翻译一定正确。

## 权重与参考音频有什么区别

| 内容 | 作用 |
| --- | --- |
| 声线权重 | 决定使用哪种已训练声音及支持的模型版本 |
| 参考 WAV | 提供这次合成的声音、语气和发声参考 |
| 参考台词 | 与 WAV 中实际说出的内容对应，帮助合成 |
| 情绪配置 | 为不同情绪选择可用参考，缺失时使用 Neutral |

主程序包包含默认 `mayuri-voice/refs/MAY_1158_Neutral.wav`，但不包含完整 GPT-SoVITS 环境和声线权重。只看到这份 WAV，不能认为发音服务已经安装完毕。26 种情绪也不要求准备 26 份参考后才能开始。

## 参考音频检查与异常原因

TTS 设置中提供参考音频状态检查，详细异常集中在 **“异常原因”** 折叠里。路径、文件、参考内容或服务状态异常时，先看具体原因，再修正对应设置。

SPP 可为缺失的情绪参考使用 Neutral；默认参考本身不可用或后端异常时，不能凭空生成可靠声音。文件检查通过也不代表模型已经加载、合成已经成功，最终要在游戏中收到文字并听到对应朗读。

## 没装发音或播放失败时

文字聊天可以单独使用，不依赖 GPT-SoVITS。安装发音组件后，先完成一次短句合成与游戏播放，再判断整个链路是否工作。

中断或部分播放时，系统按实际展示的中文片段、实际播放完成的日语片段记录交流；尚未输出的完整候选答案不会全部视为玩家已经听过。见[回复校验与失败恢复](RECOVERY.md)。

具体安装、声线来源和排错见[阶段三：聪音发音](../INSTALL.md#stage-3)与[语音进阶说明](../VOICE_SETUP.md)。界面与字幕的中英日适配已提供；中文等语音效果仍需匹配声线与实际验证。
