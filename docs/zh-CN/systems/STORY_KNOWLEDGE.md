# 剧情知识与共同经历说明

[返回系统说明入口](../README.md#systems) · [原版剧情协同](STORY_COORDINATION.md) · [好感度系统](AFFECTION.md)

适用版本：**AIChat 1.18.28 + SPP 5.10.8**。三语文档整理：2026-10-06；原测试数据仍按其记录日期理解。

聪音除了记住 AI 交谈，也会根据当前游戏进度了解原版剧情中已经发生的重要话题。原版剧情、自语和点击台词还会作为有来源的对话片段参与聊天，让之后的回应能够联系你们在游戏里已有的经历。

## 知识从哪里来

| 来源 | 提供什么 |
| --- | --- |
| 游戏进度同步 | 已完成章节、已经发生的重要剧情及当前相关状态 |
| 整理后的剧情知识 | 与已确认进度对应的事实和角色经历 |
| 原版实际台词 | 已捕获的聪音剧情、自语、点击反应等交流片段 |
| 当前档案的 AI 交流 | 你通过模组与她交谈形成的记忆和关系 |

这些来源分别处理。原版台词不是玩家通过 AI 输入的新消息；原版经历也不应被普通关系更新重复算成 AI 奖励。

## 如何避免提前透露剧情

提供给模型的剧情知识以当前可确认进度为依据。尚未发生的重要情节不能仅因为它存在于知识整理中，就全部作为已经共同经历的事实发送。

玩家自行声称“我们已经经历过某件事”，与游戏确认的进度不是同一种证据。身份、进度或状态不能确认时，系统不能凭空补出后续剧情；模型自身仍可能猜测或误答，这套适配不等于对所有措辞的绝对防剧透保证。

## 与原版好感加值有什么区别

剧情知识负责让她知道已经发生的事情；原版贡献账本负责计算原版经历带来的熟悉程度加值。两者有关联，但作用不同。

原版加值不会改写 AI 关系四维，也不能解除剧情锁、失联演出或人格边界。计算方式见[好感度系统](AFFECTION.md)，特殊阶段的输入与播放行为见[原版剧情协同](STORY_COORDINATION.md)。

## 当前能知道哪些环境信息

系统可按需要提供日期、时间等信息，但还没有完整接入当前窗景、服装、眼镜和摆件的外观描述。已经捕获一条台词，不代表聪音能读取玩家此刻所见的整个画面。

F10 工具用于整理内部编号与外观描述，见[外观采集工具](../tools/STATE_CATALOG.md)。通过聊天直接切换游戏环境和道具属于[未来开发安排](../README.md#roadmap)，不能当作本版已提供的功能。
