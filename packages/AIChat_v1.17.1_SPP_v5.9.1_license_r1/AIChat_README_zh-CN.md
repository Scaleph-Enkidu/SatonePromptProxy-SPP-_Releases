# AIChat 1.17.1 使用说明

适用于 **AIChat 1.17.1 + SatonePromptProxy 5.9.1**，以及 Steam Windows 版《放松时光：与你共享 Lo-Fi 故事》。本文随安装包放在 AIChat 组件根目录，完整教程在同层 `docs` 文件夹。

AIChat 让你在游戏里与聪音聊天；SatonePromptProxy（下文简称 SPP）在你的电脑上管理人设、记忆和模型连接。先完成文字聊天，之后再按需要加入语义回忆、聪音发音或麦克风输入。

## 能做什么

- 通过 AIChat UI 发送文字，结合游戏字幕、动画和聊天历史与聪音交流。
- 使用三个独立记忆档案，保留对话、人设与关系变化；关键词回忆已经包含在主程序中。
- 结合当前存档已经历的剧情和原版台词进行对话，遵循聪音的当前游戏状态。
- 选装语音后听聪音朗读回复，或用麦克风说话；两种语音功能可以分别安装。

## 阶段一：安装并开始文字聊天

### 放好文件，首次手动启动 SPP

1. 安装前退出游戏。在 Steam 中右击游戏 → **管理** → **浏览本地文件**，找到游戏 EXE 所在目录。
2. 将 [BepInEx 5.4.23.5 Windows x64](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip) 解压到游戏 EXE 同层，那里应有 `BepInEx` 文件夹和 `winhttp.dll`。如果 `BepInEx` 内没有 `plugins` 文件夹，就手动新建一个名为 `plugins` 的文件夹。
3. 把包里的 `AIChat.dll` 和配套 `AIChat.pdb` 放入游戏目录下的 `BepInEx/plugins`，只保留一份 AIChat 插件。
4. 你可以把整个 `SatonePromptProxy` 文件夹复制到任意位置。如果希望继续安装聪音发音组件与玩家语音识别，推荐单独建立一个文件夹进行统一管理，例如 `D:\LofiMOD`。不建议路径中包含中文。之后可以在游戏的 **AIChat UI** 中配置这个程序的路径，让 SPP 随游戏自动启动，操作方法见下方。
5. **第一次先手动双击该文件夹里的 `SatonePromptProxy.exe`，并保持 SPP 运行。** 接下来配置游戏自动启动，只对以后启动游戏生效。

### 在 AIChat UI 中设置 SPP

1. 启动游戏、进入场景，按 **F9** 打开 **AIChat UI**，点击 **展开设置**。
2. 展开 **SPP 与记忆（人格代理）**。打开自己的 `SatonePromptProxy` 文件夹，点击资源管理器上方的地址栏，按 **Ctrl+C** 复制文件夹路径。回到 AIChat UI，将路径粘贴进 **SPP 启动文件路径：** 输入框，再在末尾加上 `\SatonePromptProxy.exe`。例如 `D:\LofiMOD\SatonePromptProxy\SatonePromptProxy.exe`。
3. 勾选 **启动游戏时自动运行 SPP**。初次安装保留 **记忆 1**，然后按下面的分支设置自己的聊天服务。

### 选择一个聊天服务

展开 **LLM（聊天模型与连接）**，按你取得 Key 的服务选择以下一条路线。聊天服务需要你自己的有效 Key、可用模型和额度；模型输入框里的名称可以修改，以该服务给你的模型列表和权限为准。

**使用 OpenAI：**展开 **OpenAI** → 勾选 **选择 OpenAI（保存后生效）** → 在 **API Key（接口密钥）**填入 OpenAI Key → 在 **模型名称（可修改）**填入自己可用的模型。

**使用 DeepSeek：**展开 **DeepSeek** → 勾选 **选择 DeepSeek（保存后生效）** → 在 **API Key（接口密钥）**填入 DeepSeek Key → 在 **模型名称（可修改）**填入自己可用的模型。

**使用中转站：**展开 **中转站（第三方 API）** → 勾选 **选择 中转站（第三方 API）（保存后生效）** → 填写 **中转站 API 地址**、**API Key（接口密钥）**和 **模型名称（可修改）**。三项都使用中转站提供的信息；地址通常形如 `https://api.example.com/v1`。

每条路线都需要勾选对应的 **选择** 项；仅展开服务并不会切换。其他服务入口与进阶选项见 [完整安装指南](docs/INSTALL.zh-CN.md#stage-1)。

### 保存并发送第一句话

1. 点击 **保存并应用配置**。
2. **如果出现旧记忆选择**，按需要点击 **带入旧版记忆并继续**，或 **跳过旧版记忆，继续使用**。跳过会从新的对话记忆开始，旧记录保留；完全新装且没有旧记录时不会要求这一步。
3. 完成选择后，等待所选服务显示 **（正在使用）**。如果提示尚未连接 SPP，先确认第一次手动启动的 SPP 仍在运行。
4. 在 AIChat UI 下方输入框输入一句问候，例如“你好，聪音”，按 **Enter** 发送。看到回复即完成文字聊天安装。**现在就可以直接进行文字聊天了！**

## 日常操作

| 操作 | 默认快捷键或入口 |
| --- | --- |
| 打开或关闭 AIChat UI | **F9** |
| 发送文字 / 输入换行 | **Enter** / **Shift+Enter** |
| 按住说话，松开提交 | 完成阶段四后使用 **F8** |
| 切换独立记忆 | **SPP 与记忆（人格代理）** → **记忆档案：** → 选择后保存应用 |

**界面与行为**里的 **反转回车键行为**会交换 Enter 与 Shift+Enter 的作用。修改需要保存的设置后，点击 **保存并应用配置**。剧情进行中、聪音不在座位等状态可能暂时限制聊天，按游戏提示继续即可。

## 后续三个阶段：按需要选装

- **阶段二：ONNX 语义回忆。** 增强旧对话的换词查找；另下载模型组件，按教程放到 SPP 所在目录并校验、启用。只使用文字聊天可以跳过。见 [阶段二](docs/INSTALL.zh-CN.md#stage-2)。
- **阶段三：让聪音发音。** 安装 GPT-SoVITS 和聪音声线，先按教程启动并试听。AIChat UI → **展开设置** → **TTS（文字转语音）**可调整 **TTS 朗读语言：**和 **TTS 朗读音量：**；新装的语音服务地址已配置好，无需重新填写。完成后发送文字，聪音会自动朗读可播放的回复。见 [阶段三](docs/INSTALL.zh-CN.md#stage-3)。
- **阶段四：让玩家用麦克风说话。** 安装 Fun-ASR 并允许游戏使用麦克风后，AIChat UI → **展开设置** → **持续通话** → **选择麦克风（按住说话与持续通话共用）** → 点击设备名 → **保存并应用配置**。不用先启用持续通话；先按住 F8 说短句、松开提交，成功后再按 **开始持续通话**，结束时按 **结束持续通话**。见 [阶段四](docs/INSTALL.zh-CN.md#stage-4)。

四阶段可以按需停下或跳过：ONNX 不是语音功能的前置条件，TTS 和 ASR 也可以分别安装。AIChat UI 中的 TTS 自启选项用于启动语音服务；**界面与行为**里的原版语音选项管理游戏原版行为。

## 升级、资料与隐私

升级前退出游戏、SPP 和语音服务，备份 AIChat 配置与聊天记录，以及完整的 SPP 文件夹，再更新程序。保留个人配置、记忆、人设和已装的模型、声线；不要先删除整个 SPP 文件夹，也不要用示例配置覆盖自己的配置。具体备份位置见 [资料与隐私](docs/DATA_AND_PRIVACY.zh-CN.md)。

聊天记录和连接资料会保存在本机；使用云端聊天时，当前输入及生成回复所需的人设、相关记忆会发送给你选择的服务。Key 与额度由你管理，分享截图或日志前请隐藏 Key 和私人对话。

## 常见排查

| 问题 | 先检查 |
| --- | --- |
| F9 没有打开 AIChat UI | BepInEx 是否正确安装，AIChat DLL 是否位于 `BepInEx/plugins`；必要时查看 `BepInEx/LogOutput.log` |
| 保存时提示尚未连接 SPP | 第一次是否手动双击启动 SPP；填写的是 EXE 完整路径还是文件夹；SPP 是否仍在运行 |
| 服务没有显示“（正在使用）” | 是否勾选对应服务并保存，是否还有旧记忆选择待完成；Key、模型和额度是否有效 |
| 有文字没有声音 | 按阶段三确认语音服务、声线和试听成功，再检查 AIChat 的朗读语言与音量 |
| F8 没有识别结果 | 按阶段四确认 ASR 就绪、Windows 麦克风权限和 AIChat 中选择的录音设备 |
| 旧资料很多，启动较慢 | 等待 SPP 恢复资料，查看日志；不要重复启动多份程序或删除记忆文件 |

详细步骤见 [完整安装指南](docs/INSTALL.zh-CN.md)、[语音设置](docs/VOICE_SETUP.zh-CN.md)与[资料与隐私](docs/DATA_AND_PRIVACY.zh-CN.md)。在线查看 [统一安装指南](https://github.com/Scaleph-Enkidu/SatonePromptProxy-SPP-_Releases/blob/main/docs/INSTALL.zh-CN.md)或 [配对版本下载页](https://github.com/Scaleph-Enkidu/SatonePromptProxy-SPP-_Releases/releases/tag/AIChat-v1.17.1_SPP-v5.9.1-license-r1)。

## 界面外观

在「界面与行为」调整窗口与历史记录框的透明度；两个滑条均为 0.00 完全透明、1.00 完全不透明。「自定义聊天背景颜色」中调整 RGB 和明度，只改变历史框底色。保存并应用后生效，放弃修改恢复已保存设置。
