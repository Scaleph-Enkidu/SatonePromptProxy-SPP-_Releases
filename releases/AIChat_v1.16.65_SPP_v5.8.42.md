# AIChat 1.16.65 + SatonePromptProxy 5.8.42

CP21 配对安装包，2026-09-30。大版本跨度：从上一正式配对（AIChat 1.16.23 + SPP 5.8.26）到本次，中间包含 CP19-1（思考强度）、CP20（按存档判定的剧情知识）、CP21（原版台词时间线）与 Meta 恐怖演出可重玩，以及聊天窗的一整轮界面迭代。

## 本次更新

- **Meta 恐怖演出可以重玩了**：窗外事件改按"本局游戏会话"计阶段，每次启动游戏都从第 1 阶段重来；设置 →「Meta 恐怖演出」里新增「重置恐怖演出进度（本局立即生效）」，同一局内也能立刻重来（走 SPP 的新重置端点，幂等且原子写）。
- **结局收尾**：首次走完四阶段保持花屏（失联状态）；之后再走完按旧实现正常退出游戏。判定是持久的，重启游戏依然有效。
- **演出历史改为「本局保留、下次登录才抹除」**：花屏当下还能往上翻看整段经过；关闭游戏或强退后再登录，脚本警告与触发它们的提问才会消失，普通对话不受影响。
- **旧存档兼容**：5.8.41 及更早写下的阶段记录仍可重放，不会因为本次改动出现 `recovery_required`。
- 延续本轮之前的改动：思考强度与降档兜底、按当前存档判定的剧情知识（不剧透）、原版剧情/自语/点击台词进入本地时间线，以及聊天窗气泡、字号、单行输入、把手与缩放手柄等界面迭代。

## 安装与回退

请同时下载 `AIChat_v1.16.65.zip` 与 `SatonePromptProxy_v5.8.42.zip`，不要下载 GitHub 自动生成的 Source code ZIP。退出游戏与 SPP，把 `AIChat.dll`／`AIChat.pdb` 放进 `BepInEx/plugins`；SPP 包完整解压到固定目录（已在用的只替换 EXE 即可），保留自己的 `config.json`、API Key、人设与记忆。详细步骤见[安装教程](../docs/INSTALL.zh-CN.md)与[下载清单](../docs/DOWNLOADS.zh-CN.md)。回退时成对恢复原程序与备份，不要删除记忆来切换版本。

上一稳定配对 **AIChat 1.16.23 + SPP 5.8.26** 仍保留在[本库 packages](../packages/AIChat_v1.16.23_SPP_v5.8.26) 与其 Release 中，可随时回退。
